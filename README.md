# Interactive Sales Dashboard — Python, Streamlit & Altair

## 📊 Project Overview
Built and deployed an interactive business dashboard using Python, 
Streamlit, and Altair. The application allows users to explore and 
filter data dynamically, supporting visual analysis and 
business-focused reporting.

## 🔧 Technologies Used
- Python · Pandas · NumPy · Streamlit · Altair
- Git/GitHub · VS Code · Streamlit Cloud

## ⚙️ Features
- Interactive filters and dynamic data exploration
- Business-focused visualizations built with Altair
- Data cleaning and transformation with Pandas and NumPy
- Deployed live via Streamlit Cloud
